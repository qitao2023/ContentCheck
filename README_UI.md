# ContentCheck AutoCAD 插件 - 非模态对话框使用指南

## 快速开始

### 1. 加载插件
在 AutoCAD 命令行输入：
```
NETLOAD ContentCheck.Acad.dll
```

### 2. 打开校核对话框
输入命令：
```
CHECK
```

## 界面说明

### 对话框特性
- **浮动窗口**：对话框可以自由移动和调整大小
- **始终在前**：对话框会保持在 AutoCAD 窗口上方（可调整）
- **非模态**：在对话框打开时，仍然可以操作 AutoCAD
- **隐藏而非关闭**：点击关闭按钮（×）会隐藏对话框，而不是完全关闭

### 主要功能区域

#### 1. 设置卡片
- **校核专业**：选择要校核的专业（建筑、给排水、暖通、国网）
- **规范条文详细…**：选择具体要校核的条文
- **设置**：配置 AI 模型参数（API Key、模型、服务商等）
- **框选文字**：让用户框选特定区域提取文字
- **开始校核**：启动 AI 校核过程
- **另存报告**：导出校核结果报告

#### 2. 状态和进度
- 显示当前操作状态
- 进度条显示校核进度

#### 3. 识别文字预览
- 显示从图纸中提取的文字内容
- 支持分段高亮显示
- 标题显示绑定信息：`识别文字（N 行，M 段，关联 K 个实体）` —— K 为自动空间绑定到的图面实体数
- **点击任意一行文字**：在 CAD 中选中该行文字及其关联图面实体（与结果表双击定位一致，状态栏会提示关联实体数）

#### 4. 结果表格
- 显示校核结果
- 支持双击定位到图纸中的相关文字 **及其关联图面实体**（管线 / 图块 / 表格等）

## 文字与图面实体自动绑定

提取文字时，插件会为每条文字自动扫描邻近的非文字实体（容差 ≈ 字高 × 3，距离按曲线最近点 / 包围盒计算），
把最近最多 6 个实体与该文字绑定：

- **双击结果行**：匹配到的证据文字 + 绑定的图面实体一起在 AutoCAD 中被选中（夹点可见），便于直接查看
  "文字描述的元素"到底是哪根管、哪个设备、哪段表格，而不是只高亮文字本身。
- **绑定范围**：全图提取（打开面板自动）与「框选文字」提取都生效；框选时只在选中实体内绑定，避免绑到框外的图框等无关元素。
- **纯文字图纸**（如只有总说明文字、无图面实体）：绑定数为 0，双击行为与旧版一致，仅高亮文字。

## 常用操作

### 基本校核流程
1. 输入 `CHECK` 打开对话框
2. 选择校核专业（默认为"建筑"）
3. 点击"开始校核"按钮
4. 等待 AI 分析完成
5. 查看结果表格中的校核结论

### 框选文字校核
1. 点击"框选文字"按钮
2. 在 AutoCAD 中框选要校核的区域
3. 返回对话框，点击"开始校核"

### 导出报告
1. 完成校核后，点击"另存报告"
2. 选择保存位置和格式（Excel 或文本）
3. 报告将包含所有校核结果

## 快捷操作

### 隐藏/显示对话框
- **隐藏**：点击对话框右上角的关闭按钮（×）
- **显示**：再次输入 `CHECK` 命令

### 调整对话框大小
- 拖动对话框边框可以调整大小
- 对话框有最小尺寸限制（480×600）

### 移动对话框
- 拖动标题栏可以移动对话框位置

## 故障排除

### 对话框不显示
1. 确认已正确加载插件：`NETLOAD ContentCheck.Acad.dll`
2. 检查是否有错误消息显示在命令行
3. 尝试重新输入 `CHECK` 命令

### 校核失败
1. 检查 API key 是否配置正确
2. 确认网络连接正常
3. 查看状态栏的错误信息

### 焦点问题
- 当对话框需要与 AutoCAD 交互时（如框选文字），焦点会自动切换
- 这是正常行为，操作完成后焦点会返回对话框

## 技术说明

### 与旧版本的区别
- **界面形式**：从停靠栏改为浮动对话框
- **位置控制**：可以自由移动，不再固定在侧边
- **关闭行为**：隐藏而非销毁，便于快速重新打开

### 系统要求
- AutoCAD 2018 或更高版本
- .NET Framework 4.7.2 或更高版本
- Windows 7 或更高版本
